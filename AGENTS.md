# Workspace rules

Run Composer, Artisan, formatters and tests inside Docker. The reference at `/reference` is read-only. Use PHP 8.4 / Laravel 12. Runtime packages never import Foundry. Keep generated application ownership explicit and never execute migrations from tooling. Use Laravel Pint (Laravel preset), focused Pest/PHPUnit behavior tests and explicit strict types on new PHP. Record each completed stage in IMPLEMENTATION.md. Do not expand beyond the Catalog slice.
